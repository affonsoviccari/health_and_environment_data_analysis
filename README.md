# Health and Environment Data Analysis
This repository was used for data analysis in "Saúde e Meio Ambiente" Master Degree major.

All the analysis, visualizations were used for an preliminary article called "Fatores ambientais e doenças cardiovasculares: uma análise espaço-temporal da relação entre variáveis ambientais e indicadores de saúde nos municípios de Santa Catarina, de 2020 a 2024.", not published but showed in "Políticas de Saúde e Meio Ambiente, Univille".
